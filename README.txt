오산 AI 안전점검 실시간 분석 버전

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Netlify에서 Add new project > Import from Git으로 저장소를 연결합니다.
3. Netlify 환경변수 OPENAI_API_KEY를 서버 측에 등록합니다.
4. Deploy 후 HTTPS 주소로 휴대폰에서 접속합니다.

주의: Netlify Drop에 HTML만 업로드하면 AI 서버 함수가 배포되지 않습니다.
API 이용료가 발생하며 약 8초마다 이미지를 전송합니다. 시민 공개 전 인증/호출 제한, 동의 및 개인정보 처리방침, 보관 정책, 비용 한도를 반드시 설정하세요.
전문가 문의 자동 접수는 아직 구현되지 않았습니다.
